Reviewer: Claude (direction + code-quality gate). Builder: Codex.
Round closed: 2026-06-26. Tag: `v1.1.1` = `8a47575`.

## Goal
Behavior-preserving internal refactor: pull the hardcoded rules out of the 2448-line
`bin/ai-pm-dev.mjs` monolith into a shared `workflow-core/` that BOTH the CLI and the web API
import — killing the rule duplication where `apps/web/server/project-state.mjs` kept its own
`placeholderPattern` and a `parseQualityReport` that regex-scraped the CLI's prose output.

## Plan review (architecture gate — reviewed BEFORE coding)
Verdict: **approved with 3 required changes.** The plan was strong (characterization-tests-first,
staged batches, accurate risk list). Required changes I imposed:
1. **No live re-evaluate in Web.** The plan's "re-evaluate old `quality-report.md`" fallback
   would change v1.1.0 semantics from "recorded snapshot" to "live recompute." Required: read
   `quality-report.json` only; show UNKNOWN if absent. (This was the one place the plan would
   have silently changed user-visible behavior — caught at the plan gate, cheapest place.)
2. **`evaluatePrd` path derivation must not drift.** Keep `dirname×3(sessionPath)` byte-identical;
   pin the accessed paths (scope.md, acceptance-tests.md, handoff-{codex,v0,figma}.md) with a
   spy characterization test.
3. **Packaging guard.** `workflow-core` must be in package.json `files`, asserted by a test +
   `npm pack --dry-run --json` check — a missing dir is a silent install-breaker.

## Code review (`dea11a9` → release `8a47575`)
Verdict: **approved.** All 3 required changes implemented and pinned by tests:
- Web reads `quality-report.json || UNKNOWN`; test deletes the json and asserts UNKNOWN even

  spy test asserts identical path access.
